Quiero desarrollar una aplicación profesional de escritorio en Python utilizando Tkinter como interfaz gráfica, Pillow para el procesamiento de imágenes y OpenCV para las funciones inteligentes de análisis.

El nombre del proyecto será "PhotoPilot".

El código debe estar completamente modularizado, documentado y organizado siguiendo buenas prácticas de programación.

=========================
OBJETIVO
=========================

La aplicación permitirá procesar cientos o miles de fotografías automáticamente mediante un solo clic.

El flujo de trabajo será:

1. Seleccionar carpeta de imágenes.
2. Detectar automáticamente todas las fotografías compatibles.
3. Analizar cada imagen.
4. Aplicar recorte inteligente.
5. Aplicar mejoras automáticas.
6. Mostrar vista previa.
7. Guardar las imágenes optimizadas en una carpeta de salida.

Nunca modificar las imágenes originales.

=========================
INTERFAZ
=========================

La interfaz debe estar desarrollada con Tkinter moderno.

Debe contener:

- Barra superior con el nombre del proyecto.
- Botón para seleccionar carpeta origen.
- Botón para seleccionar carpeta destino.
- Vista previa grande de la fotografía.
- Lista lateral de fotografías.
- Barra de progreso.
- Estado del procesamiento.
- Consola inferior con mensajes.

Panel derecho con herramientas.

Botones:

• Recorte automático
• Mejorar automáticamente
• Restablecer
• Aplicar a esta foto
• Aplicar a todas
• Procesar carpeta

Usar OpenCV.

Detectar:

Personas

Objetos principales

Si existen rostros:

Mantener siempre los rostros dentro del encuadre.

Si existen varias personas:

Buscar el mejor recorte posible.

Si no existen personas:

Centrar el objeto principal.

Si no se detecta nada:

Realizar un recorte centrado.
